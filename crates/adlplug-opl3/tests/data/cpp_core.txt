# tests/common/mod.rs reproduces, for the Rust core to make as well (cpp_core.rs).
# cpp_core.cc wrote it, built against the C++ version's core as commit b4c4d0c
# has it (sources/opl3/core, its pass in C++) and against the low-level core
# drawn from a die shot of the chip, YMF262-LLE, as libADLMIDI carries it there.
#
# For each seed from 1 to 8, three lines:
#   writes <seed> <count> <hash>  the writes for 20000 samples, and an FNV-1a
#                                 hash of each one's sample (32 bits), address
#                                 (16) and value (8), little-endian
#   plain <seed> <hash>...        FNV-1a hashes of the core's samples, a hash of
#                                 every 1000, each sample as output A then B in
#                                 32 bits, little-endian
#   panned <seed> <hash>...       the same with the soft panning of a channel every
#                                 500 samples (tests/common/mod.rs, soft_pan)
# The low-level core made the plain samples too, every one of the 160000: the C++
# core's equalled them all. It has no soft panning, which is libADLMIDI's.
