The files that carry this identifier are in the public domain. No license

The Opal OPL3 emulator, which libADLMIDI keeps in src/chips/opal, came with
the Reality Adlib Tracker of Reality, and its code is in the public domain:
libADLMIDI's src/chips/opal/LICENSE.txt quotes a letter from Reality, which
says "All source code supplied with RAD is in the public domain."

A patch of patches/libADLMIDI that changes that code is in the public domain
as the code it changes is: the author named at the top of the patch dedicates
the change, and the text that explains it, to the public domain.
